Site estático preparado para publicação em GitHub Pages.
Arquivos principais:
- index.html: página pública do serviço, com links visíveis para Termos e Privacidade.
- terms.html: Termos de Serviço.
- privacy.html: Política de Privacidade.
- styles.css: estilo visual.
- .nojekyll: evita processamento Jekyll desnecessário.

Antes de enviar o app para revisão do TikTok, ajuste o nome exibido no site para corresponder exatamente ao nome do app cadastrado no Developer Portal.
