Research date: 2026-10-28. Public documentation establishes product capabilities, not this account's authenticated entitlements or successful publication. No paid subscription, advertisement, new account or generation request was initiated by this research.

## Publication: preserve the existing Buffer route

* [Buffer API](https://buffer.com/api) and [API introduction](https://support.buffer.com/en-us/articles/what-is-buffers-api-GtIYIQilz5): API access is included in Free.
* [Buffer pricing](https://buffer.com/pricing): Free permits 10 scheduled posts per channel at a time; publishing releases a slot. This is not a monthly maximum of 10. Sixty posts in a 30-day month is therefore possible in principle through replenishment, but not proven for this account.
* [Current rate limits](https://developers.buffer.com/guides/api-limits.html), re-opened by the implementing agent: Free limits are 150 requests/15 minutes, 600/24 hours, and 1,000/30 days per channel, up to 3,000. Earlier indexed documentation differed. Use a conservative local 900-call/30-day budget and obey observed `RateLimit`, `RateLimit-Policy` and `Retry-After` headers when more restrictive. Other clients consuming the same allowance are another reason to follow server headers. Do not fabricate a balance endpoint or treat a quota reset as permission to repeat an uncertain mutation.
* [Buffer schema](https://developers.buffer.com/reference): TikTok supports `isAiGenerated`. The documented `TikTokPostMetadataInput` does not establish native commercial/paid-partnership disclosure support. Affiliate/promotional videos must not be reported as a fully supported unattended publishing path without resolving required commercial disclosure. A text hashtag is not evidence of a native disclosure setting.
* [Metricool plans](https://help.metricool.com/plans-add-ons-and-api-access-explained-xux1u) and [MCP limits](https://help.metricool.com/mcp-limits-and-plan-requirements-h72jg): Free has 20 publications/month; external API requires Advanced or Custom. Free MCP access neither increases the publication allowance nor proves that GitHub Actions can use ChatGPT's connection.
* [TikTok content-sharing guidelines](https://developers.tiktok.com/docs/en/content-sharing-guidelines): Direct Post needs approved authorization and audit for public visibility. Unreviewed clients are restricted to `SELF_ONLY`; a utility limited to accounts belonging to the developer/team is explicitly outside intended use. [Upload API](https://developers.tiktok.com/docs/en/content-posting-api-get-started-upload-content) requires the user to finish posting in TikTok and is not automatic publication.

## Durable cloud storage and cost boundary

* [GitHub Releases](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases): up to 1,000 assets per release, each below 2 GiB; no documented total release size or bandwidth cap. Releases avoid storing MP4 binaries in Git history. Public repository assets are public, including unpublished videos; do not include secrets or private evidence.
* [Actions retention](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/enabling-features-for-your-repository/managing-github-actions-settings-for-a-repository): artifacts expire, normally after 90 days; public repositories permit 1–90-day retention. Artifacts are suitable for temporary test evidence, not the sole durable inventory.
* [Actions billing](https://docs.github.com/en/billing/concepts/product-billing/github-actions): standard hosted runners in public repositories are free; larger runners are charged. Artifact storage has separate allowances. Use standard runners and Releases without purchasing services; this is a current architectural cost assessment, not a guarantee of permanent service policies or this account's billing state.
